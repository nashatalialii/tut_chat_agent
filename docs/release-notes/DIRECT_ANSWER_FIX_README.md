# Direct Evidence Answer Fix v4

هذا الإصلاح يعالج التناقضات التي قد ينتجها موديل صغير مثل Qwen 2.5 3B بعد أن يكون الاسترجاع صحيحًا.

## الفكرة
عندما يكون السؤال عن مخالفة معروفة ويوجد سجل Atomic مطابق يحمل `معرف الموضوع` نفسه، يتم بناء الإجابة مباشرة من الحقول الصريحة داخل الدليل:

- `إجابة مختصرة`
- `العقوبة المذكورة`
- `العقوبة الإضافية`

بدل إرسال السؤال الواضح إلى الـLLM ليعيد تفسير النص.

الـLLM يظل مستخدمًا للأسئلة المركبة، طلب نص المادة، التصالح، والأسئلة التي لا يمكن الإجابة عليها مباشرة من سجل واضح.

## التثبيت
من جذر المشروع:

```bash
unzip -o ~/Downloads/egypt-traffic-rag-direct-answer-fix-v4.zip -d .
docker compose build backend
docker compose up -d --force-recreate backend
```

لا تحتاج إلى إعادة `pnpm ingest` لهذا الإصلاح إذا كنت بالفعل تستخدم Atomic v4 ومؤشر Chroma الحالي مبنيًا منه.

ثم اضغط «محادثة جديدة» لتجنب cache/ذاكرة إجابة قديمة، واختبر:

- ما عقوبة تجاوز السرعة؟
- لو ماشي عكس الاتجاه يحصل إيه؟
- لو بسوق من غير رخصة يحصل إيه؟

## السلوك المتوقع
الأسئلة المباشرة السابقة تُجاب من `إجابة مختصرة` في السجل المطابق بدون استدعاء الـLLM. لذلك يفترض أن تختفي عبارات متناقضة مثل «لا توجد معلومات محددة» عندما تكون العقوبة موجودة فعلًا في نفس الدليل.

يمكن التحقق من اللوج:

```bash
docker compose logs backend --tail=100 | grep rag.direct_answer
```

## التحقق المنفذ
- TypeScript strict compile للوحدة الجديدة ومكوناتها المحلية: PASS
- اختبار وظيفي للسؤال «لو ماشي عكس الاتجاه يحصل إيه؟»: PASS
- تم التحقق من أن موضوع `driving_against_traffic` يعيد النص المختصر المطابق بدل توليد LLM.
